# Set up an open, closed, or internal test

## Source Role

Play Console의 internal, closed, open testing 트랙 목적과 설정 전제, tester 관리 방식을 설명하는 공식 도움말이다.

## Storage Decision

- 공식 Help Center URL을 원본 포인터로 사용한다.
- 트랙별 현재 제한과 화면 순서는 실제 Play Console 작업 직전에 다시 확인한다.
- familyProject의 첫 업로드 절차는 프로젝트 릴리스 체크리스트에서 관리한다.

## Trust Notes

- Google Play 테스트 트랙 운영의 공식 자료다.
- 개인 개발자 계정의 production 접근 조건은 별도 공식 문서와 함께 확인해야 한다.
- internal testing과 Internal App Sharing은 서로 다른 기능이므로 혼동하지 않는다.
