# Create and set up your app

## Source Role

Play Console에서 앱 레코드를 만들 때 입력하는 기본 정보와 선언 절차를 설명하는 공식 도움말이다.

## Storage Decision

- 공식 Help Center URL만 원본 포인터로 저장한다.
- familyProject의 실제 입력 후보는 `docs/APP_PLAY_CONSOLE_SUBMISSION_PREP.md`에서 관리한다.
- 콘솔 화면 명칭이 바뀌면 원문과 실제 화면을 우선한다.

## Trust Notes

- Google Play 앱 생성 절차의 공식 자료다.
- 개발자 계정 유형, 국가와 콘솔 롤아웃에 따라 화면이 다를 수 있다.
- 계정 생성, 결제와 본인 인증 완료 여부는 이 문서만으로 확인할 수 없다.
