# Provide information for Google Play's Data safety section

## Source Role

Data Safety form의 적용 트랙, privacy policy, 데이터 수집·공유와 SDK 검토 책임을 설명하는 공식 도움말이다.

## Storage Decision

- 공식 Help Center URL을 원본 포인터로 사용한다.
- familyProject의 Data Safety 답변은 실제 빌드와 SDK를 재검토한 뒤 프로젝트 제출 문서에 기록한다.
- 정책 전문이나 제출 답변을 이 source record에 복제하지 않는다.

## Trust Notes

- Google Play Data Safety 제출 기준의 공식 자료다.
- 앱 코드뿐 아니라 포함된 SDK의 데이터 전송도 개발자가 확인해야 한다.
- internal testing 전용 면제와 이후 트랙 요구사항을 구분한다.
