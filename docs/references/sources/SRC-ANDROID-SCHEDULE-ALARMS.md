# Schedule alarms

## Source Role

Android의 inexact/exact alarm 선택, exact alarm 권한, 권한 확인과 재예약 절차를 설명하는 공식 플랫폼 문서다.

## Storage Decision

- 원문 전문은 저장하지 않고 공식 문서 URL을 원본 포인터로 사용한다.
- 파생 요약과 프로젝트 적용 판단은 `docs/knowledge/`에서 관리한다.
- 페이지의 `Last updated 2026-07-14 UTC` 표시는 수집 시점 메모로만 사용한다.

## Trust Notes

- Android 플랫폼 동작의 1차 공식 자료다.
- Android 버전과 정책에 따라 내용이 바뀔 수 있으므로 권한 또는 target SDK 변경 전에 다시 확인한다.
- API 설명과 familyProject에서 실제 관찰한 기기 동작은 구분한다.
