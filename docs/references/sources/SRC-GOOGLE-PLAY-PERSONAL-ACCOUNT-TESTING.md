# App testing requirements for new personal developer accounts

## Source Role

신규 개인 개발자 계정이 production 접근 전에 충족해야 하는 closed testing 조건과 신청 절차를 설명하는 공식 도움말이다.

## Storage Decision

- 공식 Help Center URL을 원본 포인터로 사용한다.
- tester 수와 기간은 변경 가능한 정책값이므로 수집일과 함께 기록한다.
- 실제 적용 여부는 개발자 계정 유형과 생성일을 Play Console에서 확인한 뒤 판단한다.

## Trust Notes

- 신규 개인 계정 testing 요구사항의 공식 자료다.
- 조직 계정이나 정책 적용 이전 개인 계정에 동일하게 적용된다고 추정하지 않는다.
- production 접근 승인 자체를 보장하지 않으며 신청 답변과 검토가 추가로 필요하다.
